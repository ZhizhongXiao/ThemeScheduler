# ThemeScheduler 维护清单

本文只记录正式 `0.1.3` 之后尚未完成或按需触发的工作。已完成版本结论见
[RELEASE.md](RELEASE.md)，机器证据保存在正式发布与 `artifacts/acceptance/`。

## 当前基线

- `0.1.3` 已完成自动门禁、可复现构建、Defender 和变更驱动的 Windows 实机验收；
- 正式发布位于 `artifacts/releases/0.1.3`；
- Release 全量测试与 Coverage 逐模块棘轮生效，精确数量以冻结测试报告为准；
- 当前没有阻塞发布的 P0/P1 问题，也没有已承诺的新产品功能。

## 下一轮维护候选

以下项目按真实缺陷或修改范围触发，不为提高数字机械实施：

1. 为 GUI 启动、Explorer 恢复和 Windows 组合适配器补充高风险分支测试；
2. 基线稳定后把测试按 `unit/integration/release` 分批整理，并同步测试发现规则；
3. 修改任务、生命周期、主题事务或自动编排模块时，逐文件扩大 Pyright strict 棘轮；
4. 只有获得启动耗时数据和等价回滚设计后，才评估 Task Scheduler 批量读取桥接；
5. GUI 视觉变化后补做浅色、深色、常见 DPI 和键盘往返预览；
6. 新 Windows 11 build、WebView2 或 Python/PyInstaller 版本升级时执行兼容性回归。

## 下一版本建议

下一版本宜定位为小型维护版：优先处理真实用户反馈、Windows 兼容性和依赖安全
更新，不预先扩张产品范围。若没有明确问题，`0.1.3` 可以保持为稳定版本。

## 非目标

- 不增加三个或更多时段；
- 不增加日出/日落联网计算；
- 不接管 Windows 色温“夜间模式”；
- 不接管壁纸、声音、鼠标指针或桌面图标；
- 不增加后台自动更新服务；
- 不为降低统计数字删除关键测试、事务回滚或数据校验；
- 不在缺少机器可读计划和明确授权时清理发布产物或执行 Windows 实机写入。
