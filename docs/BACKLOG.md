# ThemeScheduler 维护清单

本文记录 `1.0.0` 的历史验收状态与 `1.0.1` 维护版候选状态。阶段顺序和退出条件见
[ROADMAP_1.0.md](ROADMAP_1.0.md)；已完成版本结论见 [RELEASE.md](RELEASE.md)，
机器证据保存在正式发布与 `artifacts/acceptance/`。

## 当前基线

- `1.0.1` 正在执行统一版本验证、release 门禁和可复现双构建；
- 修复内容为主题切换成功后清除已消费的旧预告、解决静态检查诊断，并在重置时间/通知时保留完整昼夜外观；
- 按用户要求，待 `1.0.1` 发布确认后废弃 `1.0.0` 发布包，保留 Git 标签/源码历史；
- `1.0.0` 已完成自动门禁、可复现构建、Defender 和变更驱动的 Windows 实机验收；
- 正式发布位于 `artifacts/releases/1.0.0`；
- `0.1.4` 的实时外观读取修复已完成定向实机验收；
- 当前源码与发布文档已统一为正式 `1.0.0`；其 0.1.5 功能基线可分别保存 Windows 模式、应用模式、强调色、
  开始菜单/任务栏显示开关和标题栏/窗口边框显示开关；
- 自动边界不再学习用户临时颜色，计划只由首次初始化或 GUI 显式导入/编辑更新；
- `0.1.5 RC2` 已通过 577 项 release 测试、Coverage 逐模块棘轮、连续双构建、
  PE/payload 校验和 Defender 扫描；
- 动态主题兼容修复后的最新 0.1.5 候选通过 603 项 release 测试和 Coverage 棘轮；
- 完整外观人工实机矩阵已通过并恢复原配置、任务和 Windows 外观；0.1.5 已冻结为
  1.0 功能基线，但不单独冻结为正式发布。
- `1.0.0 RC6` 已通过 607 项门禁、Coverage 棘轮、双构建、PE/payload 与 Defender；
  从 0.1.5 升级、GUI、任务、健康状态、外观恢复及真实桌面用户环境零残留卸载均通过。

## 1.0 执行队列

严格按下列顺序推进；前一阶段未满足退出条件时不进入后一阶段：

1. **已完成**：0.1.5 昼夜完整外观实机矩阵通过，测试基线已恢复；
2. **已完成**：原 67 个测试文件已完成迁移；当前 70 个测试模块分布为
   unit 25、integration 34、release 11，发现等价性已证明；
3. **已完成**：GUI、Explorer、完整外观与任务桥的高风险失败分支已补齐；
4. **已完成**：五个高风险边界已逐文件达到 strict 零诊断，棘轮由 7 个扩大到 12 个；
5. **已完成**：20 样本复测显示任务桥仅占完整健康检查 p50 的约 23.0%，保留单操作桥；
6. **已完成（组合证据收口）**：build 26200 曾真实生成只有 `[Theme.A]`/`[Theme.W]`、
   不含 `[VisualStyles]` 的 `Custom.theme`；该结构已脱敏固化，并通过补全、应用验证和
   级联回滚自动测试。真实 `spotlight.theme`（有 `[VisualStyles]`、无 `ThemeId`）已由
   0.1.5 兼容候选成功应用；既有的“DWM 值可能滞后”结论也完成回归确认：公共颜色
   API 为 `#BFBFBF`、旧 DWM 值仍为 `#744DA9` 时，GUI 正确导入前者。Windows 未公开
   `.A/.W` 的稳定触发方式，因此不再通过反复切换或人为改写 `CurrentTheme` 追求
   第二次现场复现；
7. **已完成**：1.0.0 最终门禁、双构建、Defender、升级与零残留生命周期验收通过，
   正式发布目录、Git 标签和 GitHub Release 按同一源码身份冻结。

## 路线边界

- 不单独对外发布 0.1.4；其读取修复作为 1.0 基线的一部分；
- 0.1.5 可以只作为功能资格里程碑，不要求创建 GitHub Release；
- 任务桥没有达到测量阈值时保持现状，不为完成清单强行重构；
- 进入最终构建后任何源码或发布文档变化都必须重新绑定门禁报告和双构建。
- 阶段 F 已完成；后续变更进入新的维护版本，不再改写 1.0.0 冻结产物。

## 非目标

- 不增加三个或更多时段；
- 不增加日出/日落联网计算；
- 不接管 Windows 色温“夜间模式”；
- 不接管壁纸、声音、鼠标指针或桌面图标；
- 不增加后台自动更新服务；
- 不在 1.0 冻结期增加新功能；
- 不为降低统计数字删除关键测试、事务回滚或数据校验；
- 不在缺少机器可读计划和明确授权时清理发布产物或执行 Windows 实机写入。
